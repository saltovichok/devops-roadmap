# Git basics 
Working directory, staging area, repository.
********


git restore  - отмена изменений из рабочей директории


git restore --staged  - отмена изменений из индекса


git revert хэш - отменяет изменения в коммите и создает новый с правками


git show хэш - выводит информацио об объекте Git


git add  - перемещает изменения из рабочей директории в индекс.


git commit -m Описание коммита - делает снимок изменений файлов к которому позже можно будет вернуться.


git push - отправляет ваши локальные коммиты в удаленный репозиторий.Например - GitHub
