# Git basics 
Working directory, staging area, repository.


##Отмена изменений:


 - 'git restore' <файл> - отменяет изменения в рабочей директории.История не меняется.


 - 'git restore' --staged <файл> - убирает файл из индекса.История не поменяется.


 - 'git revert' <хэш> - создает новый коммит с правками прошлого.Безопасен для истории.

##Прочее:

 - 'git show' <хэш> - выводит информацио об объекте Git


 - 'git add' - перемещает изменения из рабочей директории в индекс.


 - 'git commit' -m "..." - делает снимок изменений файлов к которому позже можно будет вернуться.


 - 'git push' - отправляет ваши локальные коммиты в удаленный репозиторий.Например - GitHub
